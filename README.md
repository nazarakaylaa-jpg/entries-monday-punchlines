One joke about Monday mornings, at most 200 characters — an entry for the
[Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc)
bounty on [make.fun](https://make.fun).

## The joke

> I set five alarms for Monday morning. They unionized — all five called in sick.

79 characters. The alarms — the things meant to drag you out of bed — are the
ones refusing to work on Monday morning.

## How it works

`main.ts` (Node 22, no dependencies) writes the joke to `/output/entry.txt`:

```sh
node main.ts
```

It validates the text first: 1–200 characters, not only whitespace.
